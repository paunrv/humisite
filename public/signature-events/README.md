# Signature Events media

Drop curated assets here. The homepage reads them automatically.

```
public/signature-events/
  2018/
    poster.jpg    # 3:4
    photo-1.jpg   # 4:3
    photo-2.jpg   # 4:3
  2019/
    ...
```

Replace a file in place — no React or data edits needed.
To point at a different filename, update the path in `src/lib/signature-events.ts`.
