# Media curada — Experiencias HUMI (legacy drop folder)

Signature Events media is no longer synced from here.

1. Add JPGs under `public/signature-events/{year}/`
2. List those public paths on the event in `src/lib/signature-events.ts`

Example:

```ts
images: [
  "/signature-events/2025/sunday-funday-poster.jpg",
  "/signature-events/2025/sunday-funday-01.jpg",
  "/signature-events/2025/sunday-funday-03.jpg",
],
```
